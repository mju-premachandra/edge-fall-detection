FALL DETECTION SOFTWARE - FIRST RUN

1. Right-click FallDetection_Software.zip and choose Extract All.
   Put the extracted FallDetection_Software folder inside:
   C:\Users\janit\Desktop\Fall Detection

   You should then have:
   Fall Detection\FallDetection_Software\start_demo.bat
   Fall Detection\.venv313\Scripts\python.exe

2. Open FallDetection_Software and double-click start_demo.bat.
   The first run installs Flask, NumPy and pandas. Internet is needed for
   installation. Keep the command window open while using the software.

3. Your browser should open http://127.0.0.1:5050
   If it does not, type that address into Chrome or Edge.
   You do not need to open JupyterLab for this app.

4. FIRST TEST:
   Click Manual input.
   Click Load walking window.
   Click Analyze input.
   You should see No fall predicted and an actual backend response.

5. FALL / CANCELLATION TEST:
   Change Cancellation time to 30 seconds so you have time to inspect it.
   Click Load fall window, then Analyze input.
   You should see Suspected fall and Cancellation window open.
   Click Cancel alert. The history should show cancelled.

6. ESCALATION TEST:
   Change Cancellation time to 3 seconds, then click Analyze input again.
   Do not cancel. The alert should escalate to the local receiver.
   Click Acknowledge receipt. Check Alert history.

This demonstrates frontend -> backend -> trained ML -> output -> alert workflow.
Hardware vibration is represented by the visual alert. No real sensor, motor,
external receiver, SMS or email is connected. The cancellation time is editable;
the initial value is a demo setting, not a fixed research requirement.

IF DOUBLE-CLICK DOES NOT WORK
Open Command Prompt and run these lines one by one:

cd /d "C:\Users\janit\Desktop\Fall Detection\FallDetection_Software"
..\.venv313\Scripts\python.exe -m pip install -r requirements.txt
..\.venv313\Scripts\python.exe app.py

If the port is already in use, stop another copy with Ctrl+C, or run:
..\.venv313\Scripts\python.exe app.py --port 5051
Then open http://127.0.0.1:5051

To stop: press Ctrl+C in the command window. Closing only the browser does not
stop Python. To reopen later, double-click start_demo.bat again.

Read DEMO_SCRIPT.md for the presentation flow, API.md for team integration,
and README.md / reports\MODEL_REPORT.md for training and results.
