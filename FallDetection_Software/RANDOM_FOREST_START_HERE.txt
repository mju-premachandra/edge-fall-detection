ACTUAL COMPARISON ON PREVIOUSLY INSPECTED SUBJECTS 5-6
                     Decision tree      Random Forest
Accuracy                95.88%             97.30%
Fall precision          37.40%             49.21%
Fall window recall      82.14%             55.36%
F1 score                 0.514              0.521
False-positive windows     77                 32
Missed fall windows        10                 25

The forest has fewer false alarms but misses more labelled fall windows.
It is not an unqualified improvement. Both matched 10/10 labelled fall intervals
under the event-scoring protocol; that differs from individual window recall.
The small laboratory subset does not establish real-world reliability.

TRAINING METHOD
Same 12 features, one-second causal windows and original eligibility rules.
Train subjects 1-3; select settings on subject 4 only.
100 trees; selected max_depth=5, min_samples_leaf=5, score threshold=0.65.
Six model configurations and three thresholds were specified before this run.
Class weights: balanced_subsample; random seed: 42.
Selection objective: validation F2, followed by precision and simplicity ties.
The selected forest was saved before reading comparison sensor data.

The old test subjects 5-6 were already examined before this experiment, so call
this an exploratory reused-set comparison. New participants are needed for a
new independent final evaluation. Do not change settings based on these results
and then report them as a fresh final test.

FILES TO LEARN
train_random_forest.py: load data, train candidates, select on validation,
freeze the model, compare results, write reports.
random_forest.py: load the forest and average the learned tree scores.
model\trained_forest.json: fitted trees in a portable JSON representation.
reports\random_forest_feature_importance.csv: training impurity importances;
these are not causal effects or independent proof of feature usefulness.
