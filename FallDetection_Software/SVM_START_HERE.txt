SUPPORT VECTOR MACHINE (SVM) - THIRD ML MODEL

This adds a trained SVM to your existing FallDetection_Software project.
It uses StandardScaler + an RBF Support Vector Classifier (SVC).
Your original Decision Tree and Random Forest models stay available.

INSTALL AND TRY THE TRAINED MODEL

1. Stop your running app: click its terminal and press Ctrl+C.
   If Windows asks to terminate the batch job, enter Y.
2. Make a backup copy of your existing FallDetection_Software folder.
3. Extract FallDetection_SVM_Addon.zip into a temporary folder.
4. Copy ALL extracted contents into your existing FallDetection_Software
   folder - the folder containing app.py, core.py, model and data.
   Choose Replace for app.py, static/app.js, templates/index.html and any
   other matching update files. Merge the model, reports, static and tests
   folders. Keep the existing files within those folders.
   Do not place the contents inside a second nested software folder.
5. Start start_demo.bat as usual. Keep its terminal open.
6. Open http://127.0.0.1:5050 and press Ctrl+F5 to refresh the app.
7. Choose Support Vector Machine (SVM) in the Prediction model dropdown.
8. Choose a recording or load a manual example, then click Analyze input.
9. Switch to Decision Tree or Random Forest and analyze the same input
   again to compare. Each analysis actually uses the selected model.

The ZIP includes a trained SVM. You do NOT need to retrain before trying it.
The existing runtime/events.sqlite3 is not included or replaced. Saved
alerts remain, and their model IDs identify which model produced them.

RETRAIN ON YOUR COMPUTER (OPTIONAL)

Option A: Double-click train_svm.bat.
The launcher uses your existing .venv313 or .venv environment, installs
the existing training requirements and runs train_svm.py.
It prints progress for nine SVM configurations. Wait for the final message.
If anything fails, read the error above the prompt; the launcher stays open.

Option B: Use VS Code or Jupyter.
Open 04_SVM_Training.ipynb, choose your Python 3.13 environment and run the
cells from top to bottom. Saved outputs show a completed reference run.
They were generated by executing the plain Python cells, not through a
Jupyter kernel. Your local run may differ slightly across library versions.

Option C: In a PowerShell terminal opened INSIDE FallDetection_Software,
when .venv313 is in the parent Fall Detection folder, run:

  ..\.venv313\Scripts\python.exe -m pip install -r requirements-training.txt
  ..\.venv313\Scripts\python.exe train_svm.py

Restart the app after training. It loads the saved models at startup.

HOW THIS MODEL WORKS

1. Receive a timestamped sequence of three acceleration and three rotation
   readings from the belt IMU dataset or manual software input.
2. Extract the same 12 features used by your existing models from eligible
   one-second causal windows.
3. Standardize features using the training-only saved mean and scale.
4. Apply the learned RBF SVM to obtain a decision margin.
5. Transform the margin with sigmoid for the 0-1 display score and compare
   it with the validation-selected threshold. This score is NOT a calibrated
   probability and cannot be compared as confidence between algorithms.
6. A suspected-fall prediction can open the existing cancellation workflow.

DATA AND EVALUATION

Same real UP-Fall belt subset: subjects 1-6, eleven activities, trial 1.
Train subjects 1-3; choose settings using subject 4 only.
Subjects 5-6 have already been inspected for previous models. These new
results are an EXPLORATORY REUSED-SET COMPARISON, not a fresh final test.
Scaling is fit on training data only. No labels or subject IDs are features.
Unknown tags and unsuitable time windows use the original exclusion policy.

The SVM trained successfully, but it has more false alarms and lower F1 on
this comparison than the existing models. Present the actual results rather
than claiming a new method automatically improves performance.
See reports/SVM_COMPARISON.md for the measurements and selected settings.

There is no new hardware, physical vibration or external notification here.
This is an additional software model for your existing demonstration.
