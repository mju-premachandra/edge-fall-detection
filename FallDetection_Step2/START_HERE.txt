STEP 2 - FALL DETECTION DATASET PREPARATION

Extract the entire ZIP into your existing Fall Detection folder.
In JupyterLab open FallDetection_Step2/02_Prepare_Dataset.ipynb.
Run code cells in order with Shift+Enter, then save the notebook.
The data is included. No further downloads are required for this step.

66 original UP-Fall synchronized sensor CSVs: subjects 1-6,
all 11 activities, trial 1 only. No camera files or synthetic recordings.
Only the belt IMU is selected in the processed files.
Sources and byte-level SHA-256 checksums are in dataset_sources.json.
Raw originals are not edited. Processed tables preserve and flag invalid rows.
This notebook audits data and makes a participant split. It does not train a model.
Train: subjects 1-3. Validation: subject 4. Test: subjects 5-6.
Do not use test outcomes to choose model settings.

Original source: https://sites.google.com/up.edu.mx/har-up/
Citation: Martinez-Villasenor et al., UP-Fall Detection Dataset:
A Multimodal Approach, Sensors 19(9), 1988, 2019.
https://doi.org/10.3390/s19091988
This is a small laboratory-data prototype subset, not construction-worker validation.
